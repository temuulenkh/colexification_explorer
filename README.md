# Colexification Explorer

This repository contains source code for the [app](https://o389sd-temuulenkh.shinyapps.io/colexification-explorer/) that accompanies

Khishigsuren, Bella, Batsuren, Freihat, Nair, Ganbold, Khalilia, Chandrashekar, and Giunchiglia, Using linguistic typology to enrich multilingual lexicons: the case of lexical gaps in kinship.

Data files used by the app can be found in the main project [repository](https://github.com/kbatsuren/unimet).
